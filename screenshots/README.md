# Screenshots

This directory contains visualization screenshots for documentation.

## Adding Screenshots

To capture a screenshot of the visualization:

1. Run the application: `python main.py`
2. Open http://localhost:5000 in your browser
3. Wait for the graph to fully render (D3.js force simulation)
4. Take a screenshot and save as `visualization.png`

The visualization features:
- **Black background** (cyberpunk theme)
- **Purple keyword nodes** on the outer circle
- **Image thumbnail nodes** in the center
- **Green edges** connecting nodes
- **Interactive zoom/pan** capabilities
